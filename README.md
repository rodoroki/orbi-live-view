# Orbi Live: Earth's Window

Estamos construindo o protótipo visual do ORBI LIVE word.

IMPORTANTE: não tente construir todas as funcionalidades agora. Nesta etapa, concentre-se exclusivamente na identidade visual, estrutura geral e navegação.

O ORBI LIVE é uma plataforma de inteligência planetária que futuramente reunirá dados de NASA EONET, Windy, NOAA, USGS, webcams e outras fontes.

A interface deve transmitir:

ciência

inteligência

exploração planetária

sofisticação

confiança

tecnologia

minimalismo

Evite aparência de dashboard corporativo genérico, cyberpunk exagerado ou excesso de neon.

IDENTIDADE

Nome:
ORBI LIVE

Subtítulo conceitual:
EARTH INTELLIGENCE

Criar um símbolo minimalista inspirado em órbita, planeta e observação.

Paleta predominantemente escura:

preto profundo

azul petróleo muito escuro

verde/azul esmeralda sutil

branco e cinza para textos

cores de destaque somente quando necessárias

A interface deve utilizar bastante espaço negativo.

ESTRUTURA

Criar uma aplicação desktop responsiva com:

HEADER:
ORBI LIVE

Navegação:
PLANETA
EVENTOS
ATMOSFERA
OCEANO
EXPLORAR

Indicador:
● LIVE

SIDEBAR:
Mapa
Eventos
Timeline
Sobre o ORBI

Área principal reservada para o mapa planetário.

Criar também uma área lateral para informações contextuais.

Não utilizar dados reais ainda.

Utilizar dados fictícios apenas para demonstrar a interface.

PRINCÍPIO

O mapa similar ao google earth será o protagonista da aplicação.

Não criar dezenas de cards.

Não preencher todos os espaços disponíveis.

A experiência deve parecer uma janela sofisticada para observar o planeta.

Mantenha toda a estrutura modular porque posteriormente vamos adicionar dados reais e novas fontes.

Não altere a arquitetura para implementar APIs nesta etapa.
